06

关于本站

This Site

这个网站本身也是我的练习之一，所以顺便把做法写在这里。

手写，不用框架

纯 HTML / CSS / JavaScript，没有框架、没有构建工具、没有 CDN， 资源都在仓库里，克隆下来双击就能看。

动画只用 transform 与 opacity

滚动入场交给 IntersectionObserver，视差与进度条交给 requestAnimationFrame 节流， 不触发重排，所以在手机上也不卡。

背景不用 fixed 附件

插画与暖色叠加放在固定定位的图层里，而不是 background-attachment: fixed—— 后者在移动端容易掉帧。

推上去就自动发布

推到 main 分支后，GitHub Actions 会把静态文件打包并发布到 GitHub Pages， 通常一两分钟生效。
